# Marketing Creatives Skill

Develop creative concepts, briefs, and specifications for marketing visual assets and campaigns.

## Workflow

Make a todo list for all the tasks in this workflow and work on them one after another.

### 1. Creative Brief Intake

Ask the user for the following if not already provided:
- Campaign name and objective
- Target audience (or reference existing ICP)
- Key message or core claim
- Deliverables needed (ad banners, social graphics, video, OOH, etc.)
- Sizes and formats required (e.g., 1080x1080, 1200x628, 9:16 video)
- Brand guidelines (colors, fonts, logo usage rules)
- Tone and creative direction (playful, premium, bold, minimal, etc.)
- Deadline and production constraints
- Reference examples or inspiration (moodboard links, competitor ads)
- Platform/channel (Meta, LinkedIn, YouTube, print, etc.)

### 2. Creative Strategy

Define the creative approach:
- **Big Idea:** The central creative concept that ties the campaign together
- **Creative Theme:** Visual and verbal territory (e.g., "transformation", "speed", "trust")
- **Emotional Hook:** What feeling should the creative evoke?
- **Key Visual Direction:** Photography vs. illustration vs. motion, style notes
- **Copy Direction:** Headline approach, tone, length constraints

### 3. Concept Development

Develop 2–3 distinct creative concepts:

For each concept, document:
- **Concept Name:** Short memorable title
- **Concept Description:** 2–3 sentence narrative
- **Visual Direction:** What the viewer sees (layout, imagery, color palette)
- **Headline Copy:** Primary text
- **Subheadline / Body Copy:** Supporting text
- **CTA:** Call-to-action text and placement
- **Mood:** Adjectives describing the feeling (e.g., "energetic, confident, approachable")

### 4. Asset Specifications

For each deliverable, produce a detailed spec:

```
Asset: [Name]
Format: [File type, e.g., PNG, MP4]
Dimensions: [e.g., 1080x1080px]
Platform: [e.g., Instagram Feed]
Concept: [Which concept applies]
Headline: [Exact text]
Body Copy: [Exact text]
CTA: [Exact text + button label]
Visual Notes: [What to show, layout guidance]
Brand Elements: [Logo placement, color usage]
Animation: [If applicable — describe motion]
```

### 5. Video/Motion Script (if applicable)

For video assets, write:
- Scene-by-scene breakdown
- On-screen text (with timing in seconds)
- Voiceover script
- Music direction (tempo, genre, mood)
- End card / CTA details

### 6. Creative Review Checklist

Before finalizing, verify:
- [ ] Core message is clear within 3 seconds (for ads)
- [ ] Brand colors and fonts are correctly specified
- [ ] Logo usage follows brand guidelines
- [ ] CTA is prominent and specific
- [ ] All required sizes are accounted for
- [ ] Copy fits within character limits for platform
- [ ] Accessibility considered (contrast, alt text)

## Output Format

Deliver:
1. **Creative Brief** (full document)
2. **Concept Deck** (each concept as a structured section)
3. **Asset Spec Sheet** (table of all deliverables with specs)
4. **Copy Doc** (all final copy organized by asset)

## Wrap Up

Summarize what was created. Offer to:
- Refine a specific concept
- Write copy variations for A/B testing
- Feed copy into the content-creation skill for long-form versions
- Prepare a campaign-presentation to share with stakeholders
