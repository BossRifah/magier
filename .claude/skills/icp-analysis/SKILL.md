# ICP Analysis Skill

Build a detailed Ideal Customer Profile (ICP) by researching and synthesizing firmographic, demographic, behavioral, and psychographic data.

## IMPORTANT: Load Brand Context First

**Before starting**, read these files:
1. `brand/brand-overview.md` — current services, pricing, known social proof, and differentiators
2. `brand/icp.md` — the existing ICP draft to refine or expand (do not start from scratch if it exists)

Use the **Perplexity MCP** if connected to research competitor audiences, review customer reviews, and validate assumptions with real market data. Fall back to WebSearch if Perplexity is unavailable.

When finished, **save the updated ICP back to `brand/icp.md`** so all other skills benefit from the improved audience definition.

## Workflow

Make a todo list for all the tasks in this workflow and work on them one after another.

### 1. Gather Context

Ask the user for the following if not already provided:
- Product or service being offered
- Current customer base (if any)
- Industry or market vertical
- Geographic focus
- Any known pain points the product solves

### 2. Define ICP Dimensions

Analyze and document the following dimensions:

**Firmographic (B2B) / Demographic (B2C):**
- Company size / Individual age range
- Industry / vertical
- Revenue range / Income bracket
- Geography / Location
- Business model (B2B, B2C, SaaS, etc.)

**Behavioral:**
- Buying triggers and decision-making process
- Typical sales cycle length
- Budget authority and approval chain
- Tools and platforms they use

**Psychographic:**
- Goals and aspirations
- Fears and frustrations
- Values and priorities
- Information sources and watering holes

**Pain Points & Jobs-to-be-Done:**
- Primary problems the product solves
- Desired outcomes
- Alternatives they currently use

### 3. Identify Negative ICP

Document who is NOT a good fit:
- Company/individual types that churn quickly
- Segments with poor ROI
- Misaligned use cases

### 4. Build ICP Document

Create a structured ICP document with:
- Executive summary of the ideal customer
- Scored criteria table (must-have vs. nice-to-have)
- 2–3 example personas with names and narratives
- Qualification checklist for sales/marketing

### 5. Validation Recommendations

Suggest ways to validate the ICP:
- Customer interviews to run
- Data sources to pull from (CRM, analytics, reviews)
- A/B tests or experiments to confirm assumptions

## Output Format

Deliver the ICP as a well-structured markdown document with:
- Clear headings for each section
- Tables where appropriate
- Bullet-pointed criteria
- A one-paragraph "ICP summary statement" at the top

## Wrap Up

Summarize what was created and offer to:
- Refine any specific persona
- Map the ICP to messaging or positioning
- Feed the ICP into a research-strategy or content-creation skill
