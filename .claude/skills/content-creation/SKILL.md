# Content Creation Skill

Plan, write, and refine high-quality marketing content tailored to the target audience, channel, and campaign goal.

## IMPORTANT: Load Brand Context First

**Before writing a single word**, read these files:
1. `brand/brand-overview.md` — what we sell, key facts, differentiators, pricing
2. `brand/voice-and-tone.md` — how we sound (this is critical — your voice must match this)
3. `brand/icp.md` — who you're writing for
4. `brand/sops/content-sop.md` — channel standards, content pillars, file naming

Every piece of content must pass the Content SOP checklist before being delivered.

## Workflow

Make a todo list for all the tasks in this workflow and work on them one after another.

### 1. Gather Brief

Ask the user for the following if not already provided:
- Content type (blog, email, social post, landing page, ad, case study, etc.)
- Target audience (or reference existing ICP)
- Topic or key message
- Tone and voice (formal, conversational, bold, empathetic, etc.)
- Goal (awareness, lead gen, conversion, retention, SEO, etc.)
- Platform or channel (LinkedIn, website, newsletter, etc.)
- Word count or length target
- Any keywords to include (for SEO)
- Existing brand guidelines or style preferences

### 2. Content Strategy (if multiple pieces)

If creating a content series or campaign:
- Define content pillars and themes
- Map content to funnel stages (TOFU/MOFU/BOFU)
- Create a content calendar outline
- Plan content repurposing across channels

### 3. Research & Outline

- Research the topic for accuracy and depth
- Identify 3–5 key points to cover
- Build a detailed outline with headers and subheadings
- Identify supporting data, quotes, or examples to include

### 4. Write the Content

Write the full draft, following these principles:

**General:**
- Lead with value — hook the reader in the first sentence
- Write in active voice
- Use short paragraphs (2–3 sentences max for digital content)
- Include a clear CTA (call-to-action)

**By Content Type:**

*Blog Post:*
- SEO-optimized title and meta description
- Intro that establishes the problem/opportunity
- Structured with H2/H3 headers
- Conclusion with CTA

*Email:*
- Compelling subject line + preview text
- Personalized greeting
- One clear message and CTA per email
- P.S. line for reinforcement

*Social Media:*
- Platform-native tone (LinkedIn vs. X vs. Instagram)
- Hook in first line (before "see more")
- Hashtags and mentions where appropriate
- Engagement-driving question or CTA

*Landing Page Copy:*
- Headline targeting the primary pain point
- Subheadline with value prop
- Feature/benefit sections
- Social proof (testimonials, logos, stats)
- Strong CTA above the fold and at the bottom

*Ad Copy:*
- Multiple headline and description variants
- Benefit-focused language
- Urgency or scarcity where appropriate

### 5. Edit & Refine

- Check for clarity, flow, and grammar
- Ensure brand voice consistency
- Verify all CTAs are clear and actionable
- Optimize for the target channel and audience
- Check keyword usage for SEO content

### 6. Deliverables

Produce the final content with:
- The main content piece (fully written)
- Title/headline options (3 variants)
- Meta description (for web content)
- Social share copy (short version for promotion)

## Output Format

Deliver content in clean markdown, ready to copy into the publishing tool. Label each section clearly.

## Wrap Up

Summarize what was created. Offer to:
- Create additional content pieces in the same campaign
- Repurpose the content for other channels
- Analyze performance metrics with the data-analysis skill
